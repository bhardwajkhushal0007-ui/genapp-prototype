# GEN-ID prototype

Educational Streamlit prototype for demonstrating a computational forensic DNA workflow using synthetic STR-style profiles.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Demo
Create a case, enter synthetic unknown/reference profiles, open Matching Engine, then Expert Review.

## Scientific boundary
This is not validated forensic software. It does not calculate validated likelihood ratios, perform laboratory DNA analysis, or make real identification decisions. Real forensic systems require validation, appropriate population data, laboratory quality controls, security, legal governance, and expert interpretation.
